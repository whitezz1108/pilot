# Validator v2.1：16 次工具预算复验（2026-10-06）

本轮按用户要求将每节点、每 invocation 的 source tool 请求上限由 4 改为 16。搜索与打开共用预算，失败请求也占用次数；第 16 次之后仍可提交最终回答，第 17 次工具请求会在执行前终止。Manager 和 Compliance 各有独立的 16 次预算，A1V0 与 A1V1 使用相同上限。

保持 validator_v2_1 的程序规则、静态 prompt、检索器、policy、gold 和冻结 memo 不变。工具描述中显示的次数随实际运行上限变为 16。正文中的显式段落标识仍按保守字段协议要求登记并自行打开；本轮没有同时修改候选与正式证据的表达规则，以便观察单独扩大工具预算后的表现。
