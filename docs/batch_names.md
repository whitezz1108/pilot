# 历史批次名称

实验记录的下拉列表显示：发起用户｜北京时间（到秒）｜实际所选A/V/E/D｜选择轮数｜材料范围｜短批次ID。

选中后显示发起者、启动时间、实际条件、所选轮数、完成和失败数、实际涉及合同数、重复设置与完整计划轮次；原始批次ID及实际A/V/D组合可展开查看。显示名称不修改原始目录或run ID。

公网网关在账号验证后覆盖 `X-Pilot01-User`，程序只从该头记录发起者，不读取请求JSON里自行填写的用户名。身份保存在新批次的console_session.json和launch_selection.json中，并随JSON记录包导出。这里的用户指点击开始时使用的网页登录账号；共享账号不能区分具体自然人。后续重命名账号不修改既有批次归属。

旧记录没有发起者字段时显示“用户未记录”，不推测或回填；旧材料范围没有记录则明确显示未知。条件从所选run的冻结计划提取，完整计划数与实际所选轮数分开。上传记录中的身份只按文件记载展示；CSV仅有上传时间时显示“启动时间未记录”。时间统一按Asia/Shanghai显示。
