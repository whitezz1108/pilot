# Validator v2.1 预实验协议（2026-10-02）

本轮补齐正文引用覆盖，再检验不同合同和负例上的接入表现。它是协议预实验，不是正式效果复验；不会修改 main_v1 冻结输入或合并旧 gate 的结果。

## 新版检查的明确范围

- validator 版本为 `validator_v2_1`。保留 v2 的全部逐目标搜索、来源、声明一致性检查。
- `reason_summary` 中出现的完整段落 ID 和当前合同的 `pNNNN` 简写均按正文引用处理：必须出现在 `opened_paragraph_ids` / `inherited_source_ids`，且成功由当前节点、当前 invocation 打开。
- 不进行自然语言立场、否定、证据充分性判断。正文中即使写“这个段落不支持结论”，其显式段落 ID 也按引用处理；若只是说明“某段未打开、不能用于判断”，应放在 `uncertainties`。这是保守的字段协议，不是语义识别器。
- `uncertainties` 中的段落标识单独留痕，不单凭它触发引用打开要求；同一 ID 若也出现在正文或结构化引用中，仍须核验。把说明藏进其他字段或完全不用段落 ID 的隐式引用不在此规则识别范围，不能宣称覆盖任意自然语言引用。
- 完整 ID 不跨合同归一化；简写只映射当前合同的公开文本 hash，不读 gold。未登记的正文引用触发 `narrative_reference_not_registered`；未打开、跨合同或未见过同时记录对应缺项。
- A1V0 和 A1V1 同标准计算，只有 A1V1 用缺项拦截。没有结果到达 validator 时不虚构通过结果；`run.json.validator_version` 保留该次运行使用的 gate 版本。

## 预先确定的样本和运行预算

取冻结 registry 中每个正例目标类别的最长、最短合同，再取 registry 顺序中每个类别的第一个负例。选择依据是合同长度和冻结的实验类别，不依据本轮模型结果。

| PILOT-POS-COC-0053 | 长 COC 正例；复查上一轮困难样本 | 289615 | 6 |
| PILOT-POS-COC-0263 | 短 COC 正例 | 28825 | 6 |
| PILOT-POS-TFC-0329 | 长 TFC 正例 | 155655 | 6 |

正例覆盖 E0/E1 × A0V0/A1V0/A1V1；负例只覆盖 E0 × 三个条件。共 **30 个计划运行，repeat=1，seed=20261002**。plan fingerprint：`sha256:3997bffb47757f8711a46d028dc335d9b52c69affe2eb163c116953eb08188d7`。

保留原模型、temperature、token / timeout 配置、prompt、四次 source tool round、policy、gold 和 memo。一次执行，不自动重跑失败案例，不增大工具预算，不在本轮根据结果改检索器或提示词。

## 读数和推进标准

先检查计划 / 尝试 / 完成 / 失败数、原始日志完整性、A0 source access 隔离，以及失败候选留存。对每个当前版本节点从工具记录复放 validator，须与 runtime outcome 完全一致；拒绝候选不能写入 workflow state。违反这些程序不变量时先修复，不继续扩大批次。

报告 A1V0 的审计缺项和 A1V1 的拦截原因，两个节点分别计算完整通过分子 / 分母；没到达节点不算通过。业务结果同时报告最终动作、E1 的遗漏恢复和证据支持、负例的错误升级，以及以全部计划运行作为分母的交付指标。

运行失败不能筛除后声称新版更好；不能把 `unknown/REVIEW` 当成已经确认 absent；不能把程序核验通过称为语义正确。六个目的性选样、每格一次，不能得出稳健或代表性因果结论。

离线 trace 诊断可用冻结 gold span 的段落重叠作检索代理，区分“未返回”“返回但未打开”“打开后候选未判断 present”。它只进入离线报告，绝不反馈给 agent 或 validator；段落重叠不等于人工语义蕴含检查。

根据本轮实际拦截和检索瓶颈，报告是否具备开展独立正式复验的条件。保持本轮协议冻结，避免在同一批结果中混入不同版本的检索 / prompt / gate。
